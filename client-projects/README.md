# Client project workspaces

Each subfolder is an independent website presentation published inside the OR Creatives domain.

## Start a new client project

1. Duplicate `client-01` and rename the copy with a short project slug.
2. Replace the content, colors, typography, and assets inside that folder.
3. Add a new preview card to `clients.html` pointing its iframe and full-preview link to the new folder.

Keep every asset referenced with a relative path so each presentation remains self-contained.
