# RO Creative

Site estático de portfólio para serviços de web design na Irlanda e na Flórida.

## Executar localmente

Abra `index.html` diretamente no navegador ou inicie um servidor HTTP local:

```powershell
python -m http.server 8000
```

Depois, acesse `http://localhost:8000`.

## Estrutura

- `index.html`: página principal, estilos e interações.
- `.gitignore`: arquivos locais que não devem ser versionados.
